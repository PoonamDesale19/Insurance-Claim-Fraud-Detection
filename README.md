# Insurance Claims & Fraud Detection

## Project Overview

An end-to-end insurance claims analytics and fraud risk detection project built using AWS, SQL, Python, and Power BI.

## Business Problem

Insurance companies need to identify suspicious claims, understand fraud-risk patterns, and prioritize high-risk claims for investigation.

## Objectives

- Analyze insurance claim patterns
- Identify high-risk claims
- Detect potential fraud indicators
- Analyze claim amounts and customer patterns
- Build an interactive Power BI dashboard
- Provide business insights for investigation teams

## Fraud Risk Indicators

The project evaluates claims using:

- Frequent small claims
- High claim amount
- Investigation-related patterns
- Approval discrepancy
- Information inconsistency
- Timing risk

## Key Results

- Total Claims: **60,000**
- High-Risk Claims: **41**
- High-Risk Claim Amount: **₹109.43M**
- Total Claim Amount: **₹41,899.40M**

## Dashboard

The Power BI dashboard provides:

- Overall claims overview
- Fraud risk distribution
- High-risk claims by city
- High-risk claims by occupation
- High-risk claims by claim type
- High-risk claim amount
- High-risk claim analysis
- Customer-level claim investigation

## Disclaimer

This project is created for analytics and portfolio purposes. High-risk claims represent claims flagged by the project's fraud-risk scoring logic and should not automatically be considered confirmed fraudulent claims.
